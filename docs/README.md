## 当前状态摘要

- 当前版本仅适用于经授权的本地开发与测试；显式代理不能代表系统级过滤。
- 已实现白名单/黑名单原型、每日连续限时窗口、HTTP 完整 URL 日志和本地 30 天访问事件清理。
- 不良网站分类、申请提交/通知、远程设备身份、设备 IP、Windows 用户、浏览时长、kiosk 全屏、管理员授权退出、安装器和系统级拦截尚未完成。
- HTTPS CONNECT 未解密，只能观察到目标主机和端口；不要在文档或 UI 中声称获得加密路径/查询。
- 所有文档须与代码和已验证结果一致。新增功能时同步更新需求状态、路线图、架构/安全说明和测试。
